## ✨ 核心亮点

- 🍏 **原生 macOS 体验**：采用现代浅色高雅设计风格，自适应视网膜屏幕，双击启动独立 App 窗口，内存占用不到 30MB。
- ⚡ **毫秒级极速发现**：底层二层 UDP 广播/组播（`239.255.255.250:37020`）毫秒级发现局域网摄像头、录像机、门禁等所有设备。
- 🌐 **独创跨三层子网探测 (Subnet V20)**：突破路由器防火墙与广播域隔离限制，即使电脑与摄像头不在同一子网（如跨 `192.168.220.0/24`），也能完整抓取并管理全部设备。
- 🚀 **全新设备发现与一键激活**：自动捕获全新出厂（未激活）设备，直观标识，并在界面提供一键设置初始管理员密码完成激活。
- 📱 **真机芯片级微信小程序扫码对齐**：精准提取 176 字符芯片随机加密串，微信“海康威视客户服务”小程序扫码 100% 成功识别并返回重置口令。
- 💻 **全环境自包含**：内置 Python 独立运行时及所有动态链接库，换到任何 Mac 电脑双击即用，无需配置环境。

| 功能模块 | 说明 | 协议支持 |
|---|---|---|
| **局域网设备搜索** | 自动发现同广播域内的海康设备（IPC/NVR/DVR/门禁等） | SADP Multicast / Broadcast (`37020`) |

## 🚀 快速开始

### 方式一：双击独立桌面应用 (推荐)

项目已提供完全打包好的自包含应用：
1. 双击运行当前目录下的 **`海康威视管理工具.app`**；
2. 或者双击打开 **`海康威视管理工具-macOS-v1.0.0.dmg`**，将应用图标拖入 `Applications`（应用程序）文件夹即可。

> **免依赖提示**：即使新电脑上没有安装 Python、Homebrew 或 Xcode，均可正常双击运行！

### 方式二：一键 Shell 脚本运行

如果习惯在终端工作，直接执行：
```bash
./run_hikvision_app.sh
```
若需重启后台服务：
```bash
./run_hikvision_app.sh --restart
```

### 方式三：源码模式运行

要求系统安装了 Python 3.10+：
```bash
git clone https://github.com/proregmao/hikvision-mac-tool.git
cd hikvision-mac-tool

# 启动程序
python3 hikvision_mac_app/main.py
```
启动后终端将自动唤起桌面独立应用窗口，或在浏览器中访问：`http://127.0.0.1:23702`。

## 🔍 跨三层网段穿透探测 (Subnet V20)

### 为什么传统 SADP 搜不到跨网段设备？
网络中路由器依据 RFC 1812 规范，默认**绝不转发跨三层广播与组播数据报**。如果您的 Mac 位于 `192.168.110.x`，而摄像头位于 `192.168.220.x`，普通的 SADP 工具会显示“未搜索到任何设备”。

### 本工具的突破方案
本工具逆向实现了海康官方 Linux/Windows 最新版 SDK 的 **Subnet V20 智能多协议混合探测引擎**：
1. **并行 UDP 穿透**：向目标网段同时下发官方标准的 `inquiry` 与 `inquiry_v32` 单播探针；
2. **多协议并发指纹探测**：并发扫描目标子网主机的 TCP 8000 (SDK)、80 (HTTP)、443 (HTTPS)、554 (RTSP)；
3. **设备指纹深度认证**：请求 `/doc/script/lib/seajs/config/sea-config.js`、`/SDK/activateStatus`、ONVIF 接口，提取固件版本、激活状态与设备型号；
4. **精确网段过滤**：搜索指定网段时，系统严格过滤并只展示该网段内的设备，拒绝无关广播设备打扰。

## 🔑 密码找回与重置功能详解

针对不同年份、固件型号的海康设备，工具提供 4 大全方位找回方式：

### 1. 微信小程序扫码重置 (官方400助手)
- **原理**：调用底层芯片接口提取即时随机加密串 `EncryptString`（176 字符），并渲染为专用二维码。
- **操作**：
  1. 打开微信搜索小程序：**“海康威视客户服务”**；
  2. 依次点击：**“密码重置” → “开始重置” → “摄像机/球机” → “扫描二维码”**；
  3. 扫描屏幕生成的二维码，小程序将瞬间识别出设备并返回 **8位纯数字安全码**；
  4. 将安全码和您想设置的新密码输入网页，点击“确认提交重置密码”。
- **备选模式**：若摄像头扫码提示模糊，可切换为“400助手密文串”，复制 176 字符粘贴进小程序。

### 2. 官方 DeviceKey.xml 导入导出
- 点击 **“导出官方 DeviceKey.xml”** 下载秘钥文件；
- 发送给海康技术支持或上传到微信公众号，获取官方 `EncryptKey.xml`；
- 在面板中导入该文件并输入新密码完成重置。

### 3. 机身物理 RESET 按键指南
针对带物理复位孔的 IPC/球机，面板中附带完整物理复位图文指导：
- 拔掉电源 → 按住机身 RESET 按键不放 → 插上电源并持续按住 10~15 秒 → 松开按键恢复出厂。

### 4. 老版出厂超级计算安全码
- 针对 2017 年之前出厂的老版本 V4.x/V5.1 固件，利用真实序列号与日期种子，通过官方魔数移位算法即时算得恢复码。

## 🛠️ 批量网络参数修改

1. 在列表中勾选一台或多台设备；
2. 点击顶部 **【修改网络参数】**；
3. 输入起始 IPv4 地址（如勾选 5 台设备，输入 `192.168.110.101`，系统将自动分配 `.101`、`.102`、`.103`、`.104`、`.105`）；
4. 输入当前设备管理员密码，点击“确认下发修改”，工具将在 1 秒内完成批量配置。

## 🎥 摄像头实时视频与云台控制

根据海康威视官方 SDK 与 RTSP 流媒体规范，本工具提供了双模式实时画面查看与全功能云台控制：

### 1. 网页端无插件即时监控 (ISAPI Picture)
- **单帧极速抓拍**：输入设备管理员密码，点击【📸 立即抓拍】，后端自动通过 HTTP Digest 认证拉取即时画面。
- **连续实时监测**：点击【▶️ 开启连续监控】，系统以 1.2 秒/帧的间隔自动轮询刷新画面，无需在浏览器安装任何专有播放控件。
- **监控截图保存**：点击【💾 保存截图】，可直接将当前画面保存至 Mac `Downloads` 文件夹。

### 2. 4K/1080P 高清 RTSP 串流与外部播放器拉起
- **海康规范流地址生成**：
  `rtsp://[username]:[password]@[ip]:554/Streaming/Channels/[channel_id]`
  - 通道 1 主码流 (高清): `101`
  - 通道 1 子码流 (流畅): `102`
- **一键调起专业播放器**：
  自动检测本机已安装的 **IINA**、**VLC** 或系统播放器，点击对应按钮即可直接调起无损实时视频播放。

### 3. PTZ 云台舵盘与镜头控制
- 支持 8 向连续旋转（上仰、下俯、左转、右转及 4 个斜向）。
- 镜头变焦调节：【🔍 变倍 +】与【🔍 变倍 -】。
- 1~7 级灵敏度速度调节。

## 📦 自包含打包与构建说明

如需在本地基于源码自行重新打包应用：

```bash
# 1. 创建虚拟环境并安装打包依赖
python3 -m venv build_venv
./build_venv/bin/pip install pyinstaller pillow

# 2. 生成视网膜图标 (AppIcon.icns)
./build_venv/bin/python3 -c "from PIL import Image...; # (已集成在 build_assets 中)"

# 3. 执行 PyInstaller 静态打包
./build_venv/bin/pyinstaller HikvisionManager.spec --clean --noconfirm

# 4. 制作 DMG 安装镜像 (使用 macOS 原生 hdiutil)
hdiutil create -volname "海康威视管理工具" -srcfolder "dist/海康威视管理工具.app" -ov -format UDZO "海康威视管理工具-macOS-v1.0.0.dmg"
```

打包完成后，`海康威视管理工具.app` 与 `.dmg` 文件大小仅约 9.9 MB，具备极高的便携性。

## 🧩 技术架构与协议实现剖析

```
hikvision_mac_app/
├── main.py                     # 应用主启动入口
├── web_server.py               # 现代化 Web 服务端、原生UI渲染与RESTful API
└── core/
    ├── sadp_protocol.py        # 海康底层 SADP 报文封装与出厂算法引擎
    └── scanner.py              # 二层组播、UDP单播与Subnet V20混合扫描引擎
```

### 协议底层实现细节
- **组播地址**：`239.255.255.250:37020`
- **单播探针**：`<?xml version="1.0" encoding="utf-8"?><Probe><Uuid>...</Uuid><Types>inquiry_v32</Types></Probe>`
- **设备激活**：`<?xml version="1.0" encoding="utf-8"?><Probe><Uuid>...</Uuid><Types>activate</Types><MAC>...</MAC><Password>...</Password></Probe>`
- **密钥获取**：`<?xml version="1.0" encoding="utf-8"?><Probe><Uuid>...</Uuid><Types>getencryptstring</Types><MAC>...</MAC></Probe>`
